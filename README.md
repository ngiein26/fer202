# FER202 - Next.js App Router & Login Portal Project

A modern, responsive web application built from scratch with **Next.js 15 (App Router)**, featuring a state-of-the-art authentication portal UI, styled with custom glassmorphic CSS, and deployed live on **Vercel**.

---

## 🚀 Repository & Deployment Links

- **GitHub Repository**: [https://github.com/ngiein26/fer202](https://github.com/ngiein26/fer202)
- **Vercel Live URL**: [https://fer202-group4.vercel.app](https://fer202-group4.vercel.app)

---

## 🛠️ Local Development Setup

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run the development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

3. **Build for Production**:
   ```bash
   npm run build
   ```
